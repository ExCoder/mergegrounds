# MergeGrounds policy directory

This directory contains the repository-owned admission policy. Changes here are
executable security changes: protect them with CODEOWNERS and the repository
ruleset. Never place credentials or environment-specific secrets in policy.

`.mergegrounds/mergegrounds.toml` is the policy entry point.
`.mergegrounds/exceptions.toml` is the only allowed waiver registry.
`.mergegrounds/control-plane.lock.json` schema 2 is generated by
`python3 -I scripts/mergegrounds.py seal --write` and binds each protected file's
content SHA-256 plus committed Git executable mode. Commit all reviewed critical
controls first; sealing refuses HEAD/index/worktree divergence. Generate the lock,
then commit it separately. Verification reproduces the records from the declared
ancestor commit and compares current HEAD, index, and filesystem modes. Legacy
content-only locks fail closed and must be regenerated through a reviewed
migration. The lock detects unreviewed drift; it is an integrity tripwire, not a
cryptographic trust anchor.
